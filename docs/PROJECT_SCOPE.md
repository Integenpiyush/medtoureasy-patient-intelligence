# Project Scope

The supplied MedTourEasy PRD defines a six-week Patient Conversion & Provider Performance Intelligence workstream.

Core requirements covered in this repository:
- Validate all CSV and SQLite tables, row counts, schemas, keys and relationships.
- Reconcile funnel stages and treatment financials.
- Analyze provider, coordinator, channel, country and treatment-category performance.
- Test SLA-breach association with consultation booking.
- Build Logistic Regression and Random Forest treatment-completion models.
- Segment patients into three operational personas using normalized intent, response time, engagement and case value.
- Produce SQL analytics with joins, CTEs, aggregations and window functions.
- Quantify operational recommendations and document assumptions.
